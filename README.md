# DarkMode Sites

DarkMode Sites is a curated list of websites, applications, and browser extensions that offer a dark mode interface.

## Live Website
The project is hosted at [darkmodesites.com](https://darkmodesites.com/).

## Project Features
- Search for specific applications or websites.
- Filter by platform: Windows, MacOS, Linux, iOS, Android, and Browser Extensions.
- Categories for different types of dark mode support (e.g., Open Source, Wiki).

## Project Structure
- `index.html`: Main landing page containing the list of sites.
- `style.css`: Styling for the application.
- `js/`: JavaScript logic for searching and filtering.
- `images/`: Logo, icons, and site screenshots.
- `catagories/`: Sub-pages for specific platform categories.
- `form/`: Interface for adding new entries to the list.
- `fonts/`: Custom fonts used in the project.

## Technologies Used
- HTML5
- CSS3
- JavaScript
